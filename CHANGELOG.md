# Changelog

## 0.1.1

Terminology: "gatekeeper" is renamed to "judge" throughout (README, docs, plugin page and messages, code, tests).
This includes the plugin setting key `gatekeeper`, which is now `judge`, and the plugin action `gatekeeperStatus`, now `judgeStatus`.
After upgrading from 0.1.0, re-enter the judge settings (base URL, API key, temperature, `k`, timeout) in the plugin's settings form.
